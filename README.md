# 扣好人生第一粒扣子 · 班会课件（Electron）

一个用 Electron 做的下午班会课件，包含：

- ✅ 玻璃拟态（Glassmorphism）动态界面
- ✅ 25 页课件（封面 → 导入 → 10 个知识点 → 12 个游戏 → 总结）
- ✅ 12 个互动游戏（扣扣子、抢答、连连看、四象限、拼图、翻牌、大转盘、你说我猜、情景剧、判断题、选择题、宣誓接龙）
- ✅ 40 分钟倒计时
- ✅ 搞笑版演讲稿（`演讲稿-搞笑版.md`）

## 运行方式

### 方式一：Electron 桌面版（推荐）
需要先安装 Node.js，然后在项目目录下执行：

```bash
npm install
npm start
```

### 方式二：直接用浏览器打开
`index.html` 是纯前端（不依赖 Node），可以直接双击用浏览器打开，效果一样。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| `→` / 空格 | 下一页 |
| `←` | 上一页 |
| `Home` / `End` | 跳到第一页 / 最后一页 |
| 底部圆点 | 点击任意页快速跳转 |
| 顶部计时器 ▶ | 开始 40 分钟倒计时 |

## 文件说明

- `main.js` — Electron 主进程
- `index.html` — 课件结构
- `styles.css` — 玻璃拟态样式与动画
- `renderer.js` — 翻页、计时器、12 个游戏逻辑
- `演讲稿-搞笑版.md` — 40 分钟搞笑主持稿
